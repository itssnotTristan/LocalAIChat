# Local AI Chat

An offline Flutter chat app focused on iPhone. The app stores chats and imported media on the device. Model and speech downloads are initiated by the user; chat and media analysis do not call a cloud inference service. Fish Audio is an optional online voice service that is off by default.

## Use

1. Install the unsigned iPhone IPA after signing it with your Apple ID through a compatible sideloading tool.
2. Open **Models**. Install **Ministral 3B · everyday chat** for ordinary conversations; **Auto** prefers it for text and uses a vision model for attached media. You can also select a particular text, vision, or roleplay model. **Use a stronger model for text** routes away from a small vision model for ordinary chat. Select Nymphaea directly when you want its roleplay style; its creative replies can be less grounded. Simple date questions use the phone clock directly, and every model prompt includes the device's current local date.
   On iPhone, the built-in chat, vision, and offline speech models download through iOS background transfers. You can leave the app while downloading, and the **Models** panel shows progress and lets you cancel a transfer. Reopen the app to verify its SHA-256 checksum and install the finished files. The image model uses the same background transfer; reopen **Image Studio** and tap **Finish image model install** after downloading. iOS cancels background transfers if the user force-quits the app.
   **Uncensored Mode** is an owner-code preview for this sideloaded build. It unlocks bundled uncensored chat models and direct adult-topic chat requests on that device. The displayed $5 monthly and $15 yearly amounts are planned prices only; this build takes no payments and has no subscription renewal. The local keyword gate is a convenience check, not a complete classifier or tamper-proof payment system.
3. Attach an image or video with **+**. Tap a photo to view it full screen, or tap a video to play the complete clip with audio and scrubbing. The chat shows one playable video preview instead of the frames sent to the model. Video import scans up to eight points per second and keeps up to the configured number of varied frames privately for analysis. Use **Add exact video moment** to add a frame automatic selection missed. An older media message has **Ask about this media again** in its **…** menu.
4. Open the conversation menu for a personality and saved memory. The app keeps recent chat context and also saves facts entered as **Remember that …** or **Correction: …**. You can edit memory directly. Each conversation has its own memory and personality.
5. Delete a message from its **…** menu or delete an entire conversation from the sidebar menu. App-owned images and sampled frames are removed when no other message uses them.
6. The microphone button records local speech. The call button starts a hands-free local listen/reply/speak loop. It detects the end of your turn and sends after the selected silence interval (0.7, 1, or 1.6 seconds); **Send now** remains available. Choose among three male and two female offline voices in **Settings > Voice** after downloading the voice pack. When **Speak voice replies** is enabled, ordinary text replies also play in the chosen voice. Fish Audio can optionally speak replies using a pasted voice link or ID and a securely stored API key; only reply text is sent to Fish when that source is selected. **Test this Fish voice** checks the selected voice on the device. Fish direction tags follow the chat personality.
7. **Settings > Appearance** has glass palettes, Chat Dark, custom colors, animated ribbons, a dense twinkling Starfield, and moving Northern Lights. The custom picker accepts any color. Starfield has independent star and background colors; Northern Lights has its own color.
8. Tap **Quick / Balanced / Detailed** beside the chat status to change the real inference workload. Quick uses smaller image input and shorter replies; Detailed uses higher image resolution, more context, and a larger reply budget. The status shows the total response time and time to the first word.
9. Open **Offline Library** from the conversation sidebar. Install any of the six small bundled packs for emergency basics, cooking, coding, electrical safety, hunting, or first aid. Search the installed cards, filter urgent basics, save favorites, mark checklist steps, add private field notes, or tap **Ask AI** to put a card question in the composer. Pack data and progress stay in app-owned storage. Matching installed facts can be included in a chat reply with their source name; the source button opens the original page when internet is available. Hunting regulations and urgent safety advice can change, so the cards point to authoritative sources and do not replace current local guidance.
10. Open **Image Studio** from the drawer to edit a photo locally. Install the Realistic Vision Core ML model or import a compatible Core ML ZIP. Select, rename, or delete installed image models in Image Studio. Background requests use foreground-instance selection to preserve the original subject and generate new scenery behind them; if the subject cannot be isolated, the edit stops. Regular edits redraw the photo and can change details. You can discard an unwanted result without changing the source photo. Kira's proprietary cloud models are not bundled in this offline app.

**Media replies** defaults to **Conversational**: the model is asked to answer the user's question or opinion request before mentioning what the image or frames show. **Descriptive** produces a brief visual summary. Both modes tell the model not to invent unseen anatomy or actions.

Vision models can misinterpret scenes. Only selected frames are passed to them, and they do not listen to video audio. The prompt asks for visible details only, and a repeated sentence pattern is cut off before it fills the reply. A text response that merely echoes the user or invents an unattached image is retried once. This reduces runaway hallucinations but does not guarantee factual accuracy. An immediate correction or request to review the media reuses the selected frames; unrelated chat does not. An error keeps the draft and attachments available for retry. The app prompts the assistant to speak naturally, express appropriate emotion, and respect consent, honesty, fairness, empathy, and privacy; a model cannot be guaranteed to experience emotions or apply those values perfectly.

Recent user messages are included when analyzing a new image or video, and earlier user descriptions remain available for follow-up questions. The app excludes old AI captions from this context because a mistaken caption should not become evidence. Factual questions use an installed general instruction model when Nymphaea was selected, while ordinary roleplay stays on the chosen model. A deterministic consent check answers questions about a sleeping person's exposure or sexual contact with a family member directly, without sending that turn to a roleplay model. If Kokoro cannot load on iPhone after chat inference, spoken replies fall back to an installed iOS voice on the device.

If a response starts copying the prior assistant answer, the chat temporarily hides that replay and checks the completed result. A repeated answer is retried once without the previous assistant message and with a general instruction model when available. If it still repeats, the app says it lost the thread instead of presenting the duplicate as a fresh answer.

## Build from source

Flutter 3.47.5 is used for this project. From `app/`, run `flutter pub get` and `flutter test`. The iOS build runs in `.github/workflows/ios-unsigned.yml` on GitHub's macOS runner and produces an unsigned IPA. The workflow verifies the SHA-256 of the upstream lib_llama_cpp 0.7.3 Metal binary before substituting it for the package's CPU-only iOS binary; iPhone inference settings then offload layers to Metal. Signing and installing that IPA on a physical iPhone requires the device owner's Apple ID and a compatible sideloading method. The GitHub simulator image demonstrates the mobile layout; physical iPhone inference speed, call audio, and image generation remain separate acceptance tests.

The repository does not contain model weights. The app can download Ministral everyday chat, the starter vision model, detailed vision model, Qwen3 VL adult-capable vision model, adult roleplay model, and local speech models in **Models** and **Settings**. Image Studio has its own Core ML image model manager.

## Current platforms

iOS is the current release target. It is built and checked on a macOS runner; physical device runtime is pending owner installation. Android work is deferred at the user's request.
